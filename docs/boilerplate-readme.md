# STM32C0 + Wokwi: стартовий проєкт

Це заготовка для нових навчальних проєктів на Nucleo-C031C6. Вона не містить датчиків чи логіки Lockbox. Є лише STM32 HAL, конфігурація CubeMX, UART2 і блимання вбудованого LED на PA5. У проєкті вже налаштовано I²C1, але до нього нічого не під'єднано.

## Зробити копію

Скопіюйте всю папку під назвою нового проєкту. Не копіюйте `.git` і результати попередньої збірки, якщо вони з'являться пізніше. Приклад для Ubuntu:

```sh
cp -R ~/Projects/university/SP-Boilerplate my-project
cd my-project
make build
```

Для синхронізації між комп'ютерами можна використати `rsync` з виключенням `firmware/build/`. Основна навчальна копія на Mac; порядок передачі у VM описаний у `Study/VM-transfer.md`.

## Збірка й запуск

`make build` збирає Docker-образ з ARM GCC і створює `firmware/build/firmware.elf`, `.hex` та `.bin`. `make clean` прибирає лише згенеровану папку `firmware/build`. Команда збірки розрахована на Linux або macOS з Docker. На Windows зручно збирати в Ubuntu VM.

Wokwi запускається там, де встановлено VS Code з розширенням Wokwi. Це може бути хост Windows або Linux; VS Code всередині VM не потрібен. Відкрийте **цю копію** проєкту в VS Code, переконайтеся, що до неї передано зібрані файли, і виберіть `Wokwi: Start Simulator`. На екрані мають з'явитися `STM32C031C6 ready`, послідовні `tick` і блимання LED. Для звичайного запуску Wokwi потрібне підключення до інтернету.

## Під нову тему

1. Дайте копії власну назву й заведіть для неї окремий Git-репозиторій. У шаблоні немає `.git`, щоб історії різних робіт не змішувалися.
2. Відкрийте `firmware/firmware.ioc` у CubeMX і додайте потрібні піни та периферію. Після генерації коду звірте `firmware/Makefile` зі змінами CubeMX: генератор може його переписати.
3. Додайте компоненти та з'єднання в `diagram.json`. Потім пишіть код у `firmware/Core/Src`.
4. Для лабораторної окремо створіть PRD, опис компонентів, звіт і докази запуску. Їх навмисне немає в цій заготовці.

Шаблон прив'язаний до **STM32C031C6**. Для F411RE/F446RE недостатньо змінити рядок у `diagram.json`: потрібні інші HAL-файли, параметри компілятора й симулятор із підтримкою цієї моделі.

Основа прошивки взята з [прикладу Wokwi для Nucleo-C031C6](https://github.com/wokwi/stm32-hello-wokwi) і змінена для Docker-збірки та регулярного UART/LED. Ліцензія прикладу збережена у `LICENSE`; ліцензії ST/CMSIS — у `firmware/Drivers`.
